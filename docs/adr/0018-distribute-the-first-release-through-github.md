# 首版只通过 GitHub Releases 侧载分发

首版面向个人侧载测试，只通过 GitHub Releases 提供 APK，不以 Google Play 的内容政策和审核要求约束产品；不实现商店版 NSFW 过滤或成人内容提示。第一个 APK 由用户手动侧载，之后应用只在用户打开 `Me → 关于与更新` 时检查里程碑版本，不进行后台更新检查；展示版本说明、APK 大小和校验信息后，由用户确认并交给浏览器下载及 Android 系统安装，不静默下载或自行安装。所有更新使用同一包名和发布签名。更新前提醒创建世界备份，数据库迁移失败时停止写入并提示恢复。该选择不放宽凭据保护、数据防丢、Android 权限最小化和无障碍基础，未来若进入应用商店则另行设计发布变体。
