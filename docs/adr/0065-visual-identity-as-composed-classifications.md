# 视觉身份以分类为源，拼串给生图与角色卡兼容

#63 要把外貌做成参考侧的正式分类（风格、性别、年龄、族裔、肤色、眼睛、头发、体型；chip 与每组自由输入并存），同时配图管线和旧角色卡仍吃「固定外观」字符串。

决定：分类是资料真相，保存时拼成固定特征字符串给生图（再加常用服装与负面提示词）。导出 PNG/JSON 时既写拼好的 prompt，也把各分类写进 `visual_identity`。旧大框文本迁为「外观补充」，拼在分类后面，不丢字。风格/性别用词对齐参考（含 nonbinary / androgynous）；族裔用参考实测的八档，不另编。负向提示词、常用服装、从描述提取作为增强保留。从描述填充只补空项，已填的分类、外观补充、常用服装和负向都不覆盖。
