# 为稳定版保留完整的 UI、动效与交互优化里程碑

功能闭环完成后、最终真机验收前，必须单独交付一个可安装的 UI、动效与交互优化里程碑，不把这项工作拆散成零星美化。

该里程碑覆盖全部主要界面的信息层级、排版、间距、色彩、明暗主题、动态色、触控反馈、弹层来源、图片预览、系统返回、加载与错误状态，并使用 Apple Design、Emil Design Engineering、Animation Vocabulary 和 Review Animations 作为统一设计与审查基准。

高频导航不增加装饰性动画；每个动效都必须有反馈、状态解释或空间连续性的目的，保持短促、可中断，并遵循系统减少动态效果设置。手势驱动交互优先使用具有速度连续性的物理响应，弹层从触发来源出现并沿同一路径退出。

验收包括 API 28 与 API 36 自动化回归、关键界面明暗主题截图、放大图片与弹层交互检查、慢速或逐帧动效审查、无障碍与原生返回检查，以及 iQOO 15 Ultra 上的 120 Hz 触控与动画流畅度检查。
