# 持续使用模拟器测试并交付里程碑 APK

日常开发与回归测试优先在 Android 模拟器完成，每个可验收里程碑再发布签名 APK，由用户在 iQOO 15 Ultra 上测试真实性能、后台行为和 Local Dream 联动。更新检查、版本展示和安装跳转属于第一个可安装版本的基础能力；第一次手动侧载后，后续里程碑通过 GitHub Releases 与应用内更新入口交付。测试阶段默认使用 `Testing` 通道，版本依次为 `0.1.0-m1`、`0.1.0-m2` 等 GitHub Pre-release；四个里程碑全部完成后发布稳定版 `0.1.0`。所有 APK 必须保持相同包名和发布签名。
