# 以 Fancy OS 系统桌面作为一比一复刻基座

参考 APP fancy-ai 与当前五 Tab 关系世界不是同一套信息架构。后续开发以 fancy-ai 为可改进基座，因此顶层壳层改为 Root 驱动的系统桌面（独立 App + Dock），废弃 `World、Chats、Moments、Commons、Me` 作为主导航；视觉对齐深蓝/金色/衬线模拟系统，文案以简体中文为主并保留桌面专有英文名。社交为 Ustagram、Rebbit、Y 三个独立 App；首次体验对齐迎宾引导并可 Walk in，预置 Root/示例角色与可浏览社交内容；不做 Pro 付费墙（开放入口）。Games 仅要求 Hub 列表，Phone 仅要求联系人并可跳转 Messenger，Voice & Calls 仅保留设置页骨架；Creative Suite（Imaging/Gallery/Aura Swap）与 Hugging Face 模型下载、Binder、群组会话第一期做通；Characters 不做第三方 Browse WebView，Import 兼容 XML 与 JSON/PNG；已有增强能力全部保留并迁入对应设置与资料位置。本决策取代 ADR-0002 中以五 Tab 纵向闭环作为首版门槛的部分、ADR-0007、ADR-0025、ADR-0034、ADR-0051。
