# 生成/指令页面对齐参考，云端仍只发 OpenAI 兼容子集

#62 要把设置做成参考 APP 的「指令」「生成」两页（含可维护模板库、专家采样、重置、图像提示词编辑器），同时首发推理仍是云端 BYOK + 单一 OpenAI-compatible 协议（ADR-0013 / ADR-0014）。

决定：页面对齐参考；均衡档默认改为参考的 0.80 / 1024，精准/创意实现时对着参考点选抄录；重置按钮保留、文案去掉 llama.cpp。温度 / 最大 Token / Top_P / 选用哪套指令模板继续按 ADR-0063 继承。专家采样只存全局、不进推理配置覆盖、不写入当前云端请求体（仍只有 temperature / max_tokens / top_p）。图像提示词模板可编辑并保存，但不改配图管线——生图仍用视觉身份拼接。Top_P 与「自定义」档作为既有增强留在生成页。恢复初始模板跟参考：加回出厂三套并删除用户自建模板，警告必须写清。

## Considered Options

- **专家采样现在就塞进云端请求**：多数 Provider 会忽略或报错，和 ADR-0014 冲突——拒绝。
- **等 #56 再做生成页**：和「整页跟参考」的产品选择冲突——拒绝。
