# AI Livesaver 0.1.0-m12

第十二个可安装里程碑补上低频、以用户为中心的常驻角色间公共互动。

## 新增

- 当世界中至少有两名活跃常驻角色时，自动推进最多每 7 个事件触发一次角色间互动。
- 互动以公开 Moment 保存，并标记为 `character_interaction`；它不进入“先回应这些”、不触发关系通知，也不改变用户与角色的核心关系。
- 互动优先参考另一位角色最近的公开 Moment，生成失败按普通 Provider 失败路径处理，不产生半条内容。
- 互动轮次保留 NPC、主动消息和普通动态的既有比例，用户仍是自动世界事件的主要关注对象。

## 验证

- 单元测试覆盖互动轮次门禁和无背景角色时的普通动态回退。
- Android Lint、API 36/API 28 M12 Release 构建、覆盖安装和冷启动通过。

真实 Provider 下的角色语气、互动频率和 iQOO 15 Ultra 后台行为仍需真机验收。
