# AI Livesaver 0.1.0-m6

第六个可安装里程碑补全 BYOK Provider 的能力资格和任务级路由。

## 新增

- Provider 设置拆分为通用对话、世界事件、记忆整理和独立视觉四个任务配置；未配置的任务继承通用 Provider。
- 能力测试覆盖普通对话、SSE 流式响应、结构化 JSON 和视觉输入，并分别保存通过/失败原因。
- 支持手动覆盖能力资格，格式化世界事件仍必须通过 JSON 校验后才会写入世界。
- 世界推进、社交 AI 回应和 AI 帖子重写使用结构化 JSON；能力未验证时明确暂停，不静默消耗请求。
- 记忆回顾可使用独立任务 Provider；视觉理解只在对应 Provider 通过视觉资格或明确覆盖后运行。
- Provider 配置与能力结果继续使用 Android Keystore 保护凭据，任务配置不进入世界备份。

## 验证

- 单元测试、Android Lint、API 36 任务配置页面烟雾测试和 API 28 干净安装通过。
- API 36 覆盖安装保留 M5 世界数据；API 28 冷启动无 AndroidRuntime 崩溃。

真实 Provider 的能力测试结果、结构化输出兼容性和 iQOO 15 Ultra 网络/后台行为仍需真机验收。
