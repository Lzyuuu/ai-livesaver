# AI Livesaver 0.1.0-m3

第三个可安装里程碑把应用从关系与聊天扩展为持续存在的虚拟社交世界。

## 新增

- World 以特别关注关系和“你的圈子”为首屏核心，并聚合待回应事件、Moments、Commons 与创作队列。
- Moments 支持用户与 AI 内容、赞、平铺回应、指定成员回应、三种受众和逐条关闭 AI 回应。
- Commons 支持主题帖、嵌套回应，以及“最新 / 活跃”排序。
- NPC 作为明确披露的临时世界成员出现，并以受限比例补充社群活力。
- 世界设定与角色认知分离；Character Card V2 lore 默认进入角色认知，可手动提升为公共事实。
- 安静、自然、活跃三档世界节奏；逐角色主动消息、发帖和通知控制。
- 每日自动推理预算、失败暂停与手动恢复、智能后台推进、有限回归补演和可选持续世界。
- 默认隐藏正文的核心关系通知、23:00–08:00 勿扰，以及按需申请通知权限。
- 离场角色可经精确名称确认后永久删除；同名角色卡导入必须显式选择新建或合并。

## 验证

- Android API 36 模拟器完成升级安装与进程重启验证，原有世界数据保留。
- 已验证 Moments 受众与 AI 回应关闭、Commons 两级回复、世界设置、角色认知和删除保护。
- 单元测试、Android Lint 与 Debug APK 构建通过。

Local Dream 完整队列、图片版本、视觉理解、存储管理及备份恢复强化属于 `0.1.0-m4`。
