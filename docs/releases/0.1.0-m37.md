# AI Livesaver 0.1.0-m37

这次里程碑修正 Android 前后台返回时的世界推进触发点。

- 世界引擎现在监听 Activity 每次 `ON_RESUME`，而不是只在首次 Compose 创建时运行。
- 用户从后台返回且 Activity 未重建时，也会执行离开时长判断、一次有界补演和离线社交回应恢复。
- 仍遵守只在用户打开应用时推进、不承诺分钟级后台精度和自动推理预算上限。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
