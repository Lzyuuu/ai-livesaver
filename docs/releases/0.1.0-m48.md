# AI Livesaver 0.1.0-m48

## 世界纪事

- World 入口新增“世界纪事”，保留最近自动产生的世界事件，不再因为已读就从世界中消失。
- 纪事显示事件成员、摘要、产生时间与推理来源；点击事件仍沿用现有 Chats、Moments、Commons 导航。
- 提供“全部已读”操作，未回应事件仍由“先回应这些”单独承接，避免两个入口重复消费。
- 新增 API 28 与 API 36 Compose UI smoke 覆盖。

本版本仍是 GitHub Releases 测试版，真实 iQOO 15 Ultra 与 Local Dream 联调需要用户侧载后验收。
