# AI Livesaver 0.1.0-m10

第十个可安装里程碑修复推理配置移除后的凭据残留问题。

## 修复

- 从 Me 移除独立的世界事件、记忆整理或视觉推理配置时，同时删除对应的加密 API Key、额外请求头、模型和能力记录。
- 清理后任务恢复继承通用 Provider 的行为；Android Keystore 密钥本身不作为世界数据导出，仍由凭据生命周期管理。

## 验证

- 单元测试、Android Lint 通过。
- API 36/API 28 兼容构建门禁沿用 M9；M10 Release 覆盖升级会复用相同签名和包身份。

这次修复不改变已保存的聊天、世界事件、记忆或社交内容。
