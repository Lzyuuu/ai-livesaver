# AI Livesaver 0.1.0-m5

第五个可安装里程碑补全聊天时间线、流式回复与可追溯版本。

## 新增

- 云端 Provider 回复支持 SSE 流式显示；非流式兼容响应仍可正常使用。
- 流式草稿定期保存；应用进程意外退出后标记为中断，由用户明确重试。
- 网络失败保留错误状态与草稿，不把不完整内容写入模型上下文。
- AI 回复支持重新生成、查看生成时间与 Provider/模型来源，并恢复任一历史版本。
- 用户可从任一消息重写当前时间线；被替换消息留在本机历史，但不再参与上下文和世界推进。
- 重写时自动撤销后续关系事件、未固定记忆和受影响的对话回顾；固定记忆保留并提前提示。

## 验证

- 数据库由版本 14 迁移到 15，旧回复自动建立首个版本，原有世界数据保留。
- 使用 OpenAI 兼容 SSE 契约服务验证流式草稿、完成门禁、中断恢复、重试、重新生成与版本恢复。
- 验证时间线重写、旧历史保留、固定记忆保留、未固定记忆与对话回顾失效。
- 验证离开并重新进入聊天时，不会把仍在运行的请求误判为中断。
- 单元测试、Android Lint、API 36 覆盖升级与 API 28 干净安装门禁通过。

真实 Provider 的长回复稳定性、网络切换与 iQOO 15 Ultra 后台行为仍需真机验收。
