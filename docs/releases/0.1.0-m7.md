# AI Livesaver 0.1.0-m7

第七个可安装里程碑补全运行状态诊断，让 Provider、自动世界任务和 Local Dream 的本机状态可见、可排查。

## 新增

- Me 中新增“运行状态”入口，集中查看应用版本、Provider 主机、世界任务、预算、创作队列、存储和通知状态。
- 展示 Provider 四类能力的通过、失败和未验证状态，便于判断任务为何暂停。
- 支持在应用内检查 Local Dream 是否可达；检查失败不会影响其他功能。
- 支持分享脱敏诊断文本，只包含版本、能力、任务开关、队列、存储和错误摘要，不包含聊天正文、提示词、API Key 或完整文件路径。

## 验证

- 单元测试、Android Lint、API 36 诊断页与 Local Dream 检查烟雾测试通过。
- API 36 覆盖升级保留 M6 世界数据；API 28 干净安装与冷启动无 AndroidRuntime 崩溃。

真实 Provider、Local Dream 后台可达性和 iQOO 15 Ultra 的通知/省电策略仍需真机验收。
