# AI Livesaver 0.1.0-m33

这次里程碑把 Local Dream 的 SSE 与 raw RGB 合同提取为可回归验证的协议层。

- 统一解析 progress/complete/error/DONE 事件。
- 对尺寸、通道数、Base64 长度和 ARGB 像素转换做显式校验。
- 生成路径复用同一合同解析，保留原有队列、失败保留和重试行为。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
