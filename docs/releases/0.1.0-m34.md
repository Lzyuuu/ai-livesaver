# AI Livesaver 0.1.0-m34

这次里程碑补齐诊断导出前的用户确认流程。

- “运行状态与诊断”现在先展示脱敏内容预览，再由用户主动确认分享。
- 预览与分享共用同一份本地生成文本，避免确认前后内容不一致。
- 诊断仍只包含版本、Provider 主机、能力状态、世界开关、预算、队列、存储、通知和错误摘要，不包含聊天正文、提示词、API Key 或完整路径。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
