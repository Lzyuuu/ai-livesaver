# AI Livesaver 0.1.0-m107

- 完成独立的 UI、动效与交互优化里程碑，并以 Fancy AI 截图与参考 APK 校准视觉。
- 浅色主题使用暖白、靛蓝与淡金，深色主题使用暖黑、深蓝容器与金色动作；Android 12 以上可在 Me 主动开启动态色。
- World 圈子角色支持轻触直达对应会话，并提供遵从系统动画设置的短促按压反馈。
- Moments 与 Commons 改为内容流优先，创作入口收纳到页首，发布完成后自动收起。
- 全屏图片操作菜单从右上按钮原点展开；图片轻触、左上返回和 Android 原生返回继续保持等价退出。
- 统一 MD3 圆角与底部导航层级，使用可访问的 Material 图标替换字符图标，并为角色、Chats 与社交标题加入参考产品的衬线展示风格。

本版本仍是 GitHub Releases 测试版；120 Hz 动效、系统字体缩放与 Local Dream 真机交互仍需在 iQOO 15 Ultra 上验收。
