# AI Livesaver 0.1.0-m22

这次里程碑让角色视觉身份真正参与 Local Dream 生图。

- Moments 的 Local Dream 创作器可以选择一个常驻角色。
- 角色的外观与常用服装会自动拼接到正向提示词前，保持角色一致性。
- 角色的负面提示词会作为 `negative_prompt` 传给 Local Dream。
- 不绑定角色时保持原有自由提示词行为；重绘仍允许用户直接修改最终提示词。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- Release APK 使用与前序里程碑相同的测试签名构建。
