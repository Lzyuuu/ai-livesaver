# AI Livesaver 0.1.0-m27

这次里程碑让常驻角色的主动行为开关真正参与世界推进。

- 自动消息从已开启“主动消息”的角色中选择发起者。
- 自动 Moments 从已开启“主动发帖”的角色中选择发起者。
- 角色间公共互动只有在发起角色允许主动发帖时才会发生；NPC 活动仍保持独立的低频背景节奏。
- 特别关注角色继续优先出现在默认排序中，但不会覆盖其他角色的明确关闭设置。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- Release APK 使用与前序里程碑相同的测试签名构建。
