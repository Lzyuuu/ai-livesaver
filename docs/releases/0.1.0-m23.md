# AI Livesaver 0.1.0-m23

这次里程碑补齐了从 Local Dream 导入图片时的参数回收。

- 导入图片时可以粘贴 Local Dream JSON 或 `key: value` 参数文本。
- 自动恢复正向提示词、负面提示词、种子、步数、CFG、采样器和尺寸。
- 已恢复的提示词作为媒体描述复用；只有没有提示词时，才继续依赖用户填写或主动视觉理解。
- 参数随媒体记录保存，后续查看、重绘和备份不会丢失。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- Release APK 使用与前序里程碑相同的测试签名构建。
