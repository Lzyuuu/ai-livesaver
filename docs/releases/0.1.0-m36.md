# AI Livesaver 0.1.0-m36

这次里程碑加固自动世界生成的并发边界。

- JobScheduler、持续世界、返回补演和建世首轮共用一个原子生成闸门，同一时刻最多发起一条自动世界推理。
- 被并发请求跳过时不会消耗预算或写入事件；Provider/数据库异常也会释放闸门并回报失败状态。
- 保留既有的重试、任务暂停、补演来源和 Provider provenance 行为。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
