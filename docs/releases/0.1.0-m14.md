# AI Livesaver 0.1.0-m14

这次里程碑补齐长期记忆的自动捕获闭环。

- 用户消息中的明确事实仍然即时保存，不增加额外 Provider 请求。
- 可能包含个人事实的消息才会交给 Memory Provider；请求只包含当前用户消息，不携带聊天历史、角色记忆或图片。
- Memory Provider 必须通过结构化能力资格；返回 `NONE` 时不创建记忆。
- 记忆写入前再次确认来源消息仍属于当前时间线；从旧消息重写后返回的结果会被丢弃。
- 自动捕获的记忆继续显示来源消息、生成时间和所属角色，并可在上下文中编辑、删除或固定。
