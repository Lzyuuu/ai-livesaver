# AI Livesaver 0.1.0-m4

第四个可安装里程碑完成本地生图、媒体理解、离线续回与世界备份闭环。

## 新增

- Local Dream 顺序创作队列：保留提示词、负面提示词、步数、CFG、调度器、尺寸、种子和失败原因。
- 返回应用时自动检测并续跑队列；显示 SSE 进度，成功前不发布需要图片的动态。
- 支持系统照片选择器导入图片；可填写隐藏媒体描述或逐图授权视觉 Provider 理解。
- 独立视觉 Provider 配置；未配置时回退通用 Provider，请求只携带当前图片和描述任务。
- 单击图片全屏查看，双击直接打开图片操作；菜单、版本历史和多行提示词编辑均保留在全屏层。
- 重绘创建新图片版本，可恢复或删除旧版本，不覆盖原图。
- 显示创作队列与媒体占用；存储空间临界时暂停生成和导入。
- 离线聊天消息先保存在本地，恢复连接后由用户手动确认继续请求回复。
- 完整与轻量世界备份升级为格式 2；排除 Provider 凭据，校验归档、数据库和关联完整性，并原子替换当前世界。
- “重建世界”保留 Provider 与世界偏好；“清除全部应用数据”独立提供，二者均要求输入应用名称确认。

## 验证

- Android API 36 模拟器完成 `0.1.0-m3` 覆盖升级，数据库由版本 12 迁移到 14，原有角色和社交内容保留。
- 使用 Local Dream 官方 HTTP/SSE 边界的本地契约服务验证 unavailable/ready 转换、返回续跑、进度、RGB 解码、发布门禁和双版本重绘。
- 验证系统照片选择器、隐藏媒体描述、全屏三种退出方式、菜单返回层级及五行提示词编辑。
- 验证完整/轻量导出、无凭据清单、损坏备份拒绝、完整替换恢复、世界重建及恢复。
- 单元测试、Android Lint、API 36 关键旅程与 API 28 干净安装门禁通过。

Local Dream 在骁龙 NPU 上的真实生成速度、温度、后台恢复和 OEM 行为仍需在 iQOO 15 Ultra 上验收。
