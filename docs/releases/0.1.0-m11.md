# AI Livesaver 0.1.0-m11

第十一个可安装里程碑加固 Local Dream 伴生应用入口。

## 修复

- Local Dream 未安装、没有可启动 Activity 或启动被系统拒绝时，应用现在留在当前页面并显示“不可用”，不再让 `ActivityNotFoundException` 冒泡。
- 已安装并可启动的 Local Dream 仍沿用原生 Activity 跳转，返回应用后继续检查队列。

## 验证

- 单元测试、Android Lint 通过。
- API 36/API 28 M11 Release 覆盖安装和冷启动通过；签名与包身份保持连续。

Local Dream 的真实模型加载、NPU 性能和 OEM 后台行为仍需 iQOO 15 Ultra 验收。
