# AI Livesaver 0.1.0-m31

这次里程碑把 BYOK 的 fallback 路由贯通到聊天、世界事件、记忆、视觉理解和社交回应。

- 在 Provider 配置中增加显式的“备用 Provider”编辑入口，按任务分别保存。
- 只有用户保存备用配置后才会尝试 fallback；默认不会静默切换模型或账号。
- 主 Provider 失败且尚未产生流式内容时才切换备用 Provider，避免重复或拼接半条回复。
- 生成内容、世界事件和聊天回复保留实际成功的 Provider 与模型 provenance。
- 新增 fallback 路由单元测试和 Android UI 烟测。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
