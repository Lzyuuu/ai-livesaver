# AI Livesaver 0.1.0-m16

这次里程碑补齐了 Moments / Commons 的离线参与闭环。

- 用户发布的内容始终先写入本地世界，不依赖 Provider 在线状态。
- AI 回应遇到网络型失败时，会保存为可恢复的本地回应任务，不伪造回复。
- 应用重新打开且检测到网络后，自动尝试恢复一条待回应任务；成功才消耗自动预算并移除任务。
- Moments / Commons 显示等待中的 AI 回应数量，避免用户误以为内容丢失。
- 帖子删除时通过外键级联清理对应回应任务；数据库自动升级到版本 17。
- M16.1 修复联网恢复路径的存储句柄关闭问题，避免应用冷启动崩溃。
