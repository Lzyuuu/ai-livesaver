# AI Livesaver 0.1.0-m109

- Chats 参考 Fancy AI 的 Messenger 重构为完整关系入口：保留产品标题、角色与对话搜索、角色管理入口、最近消息摘要和特别关注标识。
- 私聊从会话列表进入，屏幕返回与 Android 原生返回都会回到列表；从 World 或通知直达角色时仍可直接打开对应私聊。
- 消息编辑器固定在底部，改为圆角多行输入框与单一发送按钮；历史消息独立滚动，空对话不再把输入框悬在页面中间。
- 首次建世仍不伪造角色，并以三步关系路径解释 Provider、首位角色与第一段对话如何让世界开始。
- 高频 Chats 导航不增加装饰性转场；可点击卡片继续使用 Material 即时触控反馈，消息自动滚动继续遵循系统移除动画设置。

本版本仍是 GitHub Releases 测试版；软键盘、长对话滚动和 120 Hz 触控仍需在 iQOO 15 Ultra 上验收。
