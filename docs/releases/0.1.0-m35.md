# AI Livesaver 0.1.0-m35

这次里程碑修正全屏图片预览的菜单状态同步。

- 同一张图片先普通打开、再通过双击或右上角操作请求菜单时，菜单请求会覆盖旧的 Compose 保存状态。
- 进入新的预览请求时会关闭残留的提示词编辑和版本列表层，保证菜单直接显示在当前放大图片上。
- 保留单击图片、左上返回和 Android Back 三种退出路径。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
