# AI Livesaver 0.1.0-m13

这次里程碑把“关系状态”从只读摘要补成可追溯、可纠正的用户控制闭环。

- Chats → 上下文新增关系状态卡：显示当前称谓、摘要、来源、生成时间和所属角色。
- 用户可以编辑关系称谓与摘要；修改会新增 `user_correction` 事件，旧状态保留在关系变化记录中。
- 用户可以固定或取消固定当前关系。固定后，自动关系推进不会覆盖当前状态。
- 关系变化记录保留自动推进和手动修正，并标记当前状态。
- 数据库版本升级到 16；既有世界会自动迁移，Android Studio 工程与 Gradle 配置继续随 Git 提交。
