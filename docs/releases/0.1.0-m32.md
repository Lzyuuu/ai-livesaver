# AI Livesaver 0.1.0-m32

这次里程碑让更新确认页直接展示 APK 的 SHA-256。

- GitHub Releases 检查仍只在用户打开更新页并点击检查时执行。
- 找到 `.sha256` 资源时，应用会读取并展示 64 位 SHA-256 值。
- 保留 release notes、APK 大小、校验文件状态和备份提醒，再交给系统浏览器/安装器处理下载与安装。
- 增加 checksum 解析回归测试。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
