# AI Livesaver 0.1.0-m9

第九个可安装里程碑把最小隐私保护说明放进 Me，让用户在本机直接了解数据边界与权限行为。

## 新增

- Me 中新增“隐私与数据”页面，说明本机保存、无遥测、Provider 凭据保护、图片/视觉理解边界和 Android 权限。
- 明确 Local Dream 与主应用生成图片不会上传视觉 Provider；只有用户主动上传且逐条开启理解的未描述图片才会发送。
- 明确首版尚未提供整库加密、应用内锁和加密备份，避免把设备沙箱误解为完整安全方案。

## 验证

- 单元测试、Android Lint、Debug 构建通过。
- API 36 模拟器验证 Me → 隐私与数据页面渲染和原生返回；无 AndroidRuntime 崩溃。
- Manifest 保持 `allowBackup=false`，仅保留网络、上下文通知和用户主动开启持续世界所需能力；API 28/API 36 版本与冷启动门禁通过。

首版隐私基线仍依赖设备锁屏和系统文件沙箱；真机侧载时请妥善保管未加密的世界备份文件。
