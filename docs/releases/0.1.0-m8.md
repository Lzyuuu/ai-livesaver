# AI Livesaver 0.1.0-m8

第八个可安装里程碑修复 World 世界入口中的可见交互断点，让入口卡片的动作都能回到对应的世界空间。

## 修复

- 关系主卡的“查看近况”现在进入 Moments。
- “你的圈子”中的“添加”现在进入世界成员管理。
- “创作队列”的数量入口现在进入 Local Dream 页面，便于打开伴生应用、检查连接和处理队列。
- 保留 MD3 入口层级与原生返回行为；这些动作不改变当前世界数据。

## 验证

- 单元测试、Android Lint、Debug 构建通过。
- API 36 模拟器验证查看近况、圈子添加和创作队列三条导航路径，并确认无 AndroidRuntime 崩溃。
- API 28 兼容门禁沿用 M7 已验证的干净安装与冷启动结果。

本里程碑仍需在 iQOO 15 Ultra 上验收 Local Dream 返回路径和 OEM 后台行为。
