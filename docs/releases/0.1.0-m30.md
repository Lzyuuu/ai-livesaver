# AI Livesaver 0.1.0-m30

这次里程碑补齐关系通知的锁屏隐私边界。

- 默认关系通知使用私密可见性，锁屏不公开消息正文。
- 只有用户主动开启“在通知中显示消息正文”后，通知才使用公开可见性。
- 通知频道也固定为默认私密，避免旧频道设置让正文意外暴露。
- 新增回归测试，锁定默认私密与显式预览两种行为。

## 验证

- `./gradlew testDebugUnitTest lintDebug assembleRelease`
- `./gradlew connectedDebugAndroidTest`（API 36 与 API 28 模拟器）
- Release APK 使用与前序里程碑相同的测试签名构建。
